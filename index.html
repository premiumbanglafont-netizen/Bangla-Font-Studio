How it works

A practical, browser-only font inspection workflow.

Read & preview

The app reads the font locally and uses the browser FontFace API for a real font preview. Your font is not sent to a server.

Metadata export

For TTF/OTF, the editor rewrites the name table and vendor ID while preserving the other SFNT tables and recalculating directory/checksum information.
